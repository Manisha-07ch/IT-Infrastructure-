About This Portfolio

This portfolio demonstrates hands-on IT infrastructure lab work based on Windows Server 2016 training projects. The projects cover Active Directory Domain Services (AD DS), DNS, DHCP, SMB/NTFS permissions, Group Policy, Windows Server Backup, firewall/event logging, file-server management, DFS and RRAS remote access VPN.

The lab scenarios use the fictional company Aster Business Services and are designed as training simulations, not production deployments or employment experience.

Featured Projects

01 — New Office Infrastructure

MCSA-P01Foundation

Designed and implemented a Windows Server office infrastructure for a fictional 60-user organisation.

  • Built domain controller and Windows Server lab VMs.
  • Implemented AD DS and DNS.
  • Configured DHCP and domain membership.
  • Created users, groups and controlled departmental shares.
  • Configured SMB/NTFS permissions and Group Policy.
  • Implemented Windows Server Backup and recovery testing.
  • Validated firewall and event-log controls.

02 — Controlled Document Centre

MCSA-P02File Services

Built a controlled document-management lab using Windows Server file-services technologies.

  • Configured FSRM quotas.
  • Implemented file screening.
  • Built a second file server.
  • Created DFS Namespace.
  • Configured DFS Replication and convergence testing.
  • Applied SMB permissions.
  • Created backup and restore validation.

03 — Remote Employee Access

MCSA-P05RRAS/VPN

Implemented a simulated remote-access service allowing an authorised employee to reach an internal HR share through a VPN tunnel.

  • Configured RRAS remote access.
  • Implemented L2TP over IPsec in the lab.
  • Configured routing and return paths.
  • Configured dial-in authorisation.
  • Validated DNS and SMB access through the tunnel.
  • Used RDP with NLA without exposing RDP directly to the WAN.
  • Tested remote-access revocation.
